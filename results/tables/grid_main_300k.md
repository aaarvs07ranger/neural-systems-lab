# Original ladder — main tables (300k environment steps)

Generated by `scripts/make_tables.py` — do not edit by hand. 5 house pairs × 5 training seeds per agent type. Square brackets = 95% CI (stratified bootstrap over seeds within each house, from `scripts/robust_stats.py`); 'houses' = lowest–highest of the five per-house means.
