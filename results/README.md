# What is in `results/`

Every agent is trained in **house A only** and then evaluated, frozen, in visually changed copies of it. The house pairs are P0–P4; each has five training seeds. A "cell" folder such as `pair3_seed1/` holds one trained agent's tables.

## Result sets (one folder each)

| folder | what it is | agents | notes |
|---|---|---|---|
| `ladder_300k/` | **Main results.** The cumulative ladder A → L1 → L2 → L3 after 300k training steps. | all 8 | Headline numbers. |
| `ladder_150k/` | The same ladder after 150k training steps. | PPO, PPO+Aug, DreamerV3, TD-MPC2 | Appendix: shows augmentation's benefit disappears with more training. |
| `ladder_300k_reeval/` | The `ladder_300k` models evaluated a second time, adding the L2noT house (goal object unchanged). | PPO, PPO+Aug, DreamerV3, TD-MPC2 | Repeatability check and the goal-appearance control. |
| `ladder_300k_retrained/` | Seven runs retrained because their saved models were lost. | DreamerV3, TD-MPC2 | Used only to compare an agent with itself (L2noT vs L2). Never the headline. |
| `single_change_300k/` | Every `ladder_300k` model evaluated in the one-change-at-a-time houses (walls/floor, lighting, sky, other objects, goal object, clutter) plus the cumulative rungs, in one pass. | all 8 | Which change does the damage. |
| `reordered_ladder_300k/` | The ladder reordered so each rung does more damage: clutter → + lighting & sky → + object appearance → + walls/floor/ceiling, plus each rung alone. | all 8 | Completed 2026-09-30. |
| `pilot_one_house/` | July–August runs in one house (P0), original protocol, 150k steps. | PPO, PPO+Aug, DreamerV3, TD-MPC2 | Superseded by the ladders. `superseded/` holds early undertrained DreamerV3 runs. |

## Shared folders

| folder | what it is |
|---|---|
| `tables/` | Every table the paper uses, generated by scripts from the folders above. Never edit by hand. |
| `plots/` | Figures, generated the same way. |
| `tracker/` | `runs.csv`: one row per (trained agent, house), with the commit, job, recipe and path it came from. |
| `checkpoints/`, `logs/`, `videos/` | Local scratch only, not in git. |
