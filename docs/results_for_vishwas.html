Where embodied RL agents break under visual change

Phase-1 benchmark results · Neural Systems Lab · 17 September 2026
Aarav Srivastava, with Vishwas Sathish and Rajesh Rao · target venue: LEAP workshop @ CoRL 2026 (deadline 7 Oct)

One-paragraph summary. We built a benchmark of five pairs of ProcTHOR houses that are physically identical but look different, with the difference applied in controlled steps. We trained six agent types on it — 150 agents in total, 5 houses × 5 seeds each — and measured how much each loses when only appearance changes. Every agent loses a great deal from a change a person would call cosmetic. World models lose least. Domain randomisation helps only at a small training budget and stops helping when agents are trained to convergence. Large frozen pretrained encoders (I-JEPA, MAE) do not help at all. Model-free agents specifically depend on what the target object looks like. And which change hurts is not predicted by how much of the image changed.

1. The question

An agent trained to find a fridge in one kitchen should still find it after the walls are repainted. The room is the same shape, the fridge is in the same place, the task is unchanged. Humans find this trivial. The question is whether current embodied RL agents do, and if not, exactly where and why they fail.

This matters beyond navigation. If an agent's internal representation stays tied to surface appearance, it cannot transfer a learned skill to a new instance of the same situation — which is the central obstacle to long-horizon planning in real environments. Our lab's longer-term programme (a task-informed perceptual bottleneck plus a clone-structured cognitive graph) is a proposed fix. This paper is the evidence that a fix is needed, and the specification of what it must fix.

The gap in existing work. Domain-generalisation benchmarks typically change many things at once, so when an agent fails you cannot say what broke it. We change one thing at a time, and hold the physics fixed, so every failure is attributable.

2. The benchmark

Five house pairs from ProcTHOR-10k, spanning 128 to 681 reachable floor cells. In each pair, house A is where the agent trains; the other houses are the same house with appearance changed in cumulative steps:

rungwhat changespaper name
Anothing — the training houseA
L1wall and floor materials, lighting, skyboxL1
L2noTL1 + every object's appearance except the targetL2
L2L1 + every object's appearance including the targetL3
L3L2 + distractor objects addedL4

L2noT is the designed control. L2noT and L2 differ in exactly one thing: whether the target object itself was restyled. Comparing them isolates "does the agent depend on what the goal looks like?" from "does it depend on the room looking familiar?"

The houses are verified, not assumed. Every variant passes a runtime check on three independent simulator loads: identical reachable floor cells, identical start poses, identical target count. This caught real bugs — restyled furniture with different collision shapes silently blocking floor cells, and distractor objects falling to the floor and blocking navigation.

A subtle bug worth reporting. The agent has no interaction actions, but its physical collider still nudges objects as it walks past. Over an evaluation this accumulated until an object came to rest on a pinned start pose. Every object in every house is now fixed in place. This also means earlier training runs were slowly degrading their own environment — a limitation of our pre-fix results, disclosed.

Identical step budget across agents (300k environment steps)The fairness currency. Without it no cross-agent claim survives.

On the two frozen encoders. These are ordinary PPO with the trained CNN replaced by a large pretrained vision transformer that never updates; only the small policy head learns. They are a matched pair: same architecture, same size, same ImageNet-1K pretraining data, frozen identically. The only difference is what each was originally trained to predict — MAE redraws missing pixels, I-JEPA predicts the representation of missing regions. That isolates the prediction-target question with everything else held fixed.

Terminology, to be precise: neither is a world model. Both predict within a still image — no time, no actions. The member of the JEPA family that is genuinely a world model is V-JEPA 2-AC (action-conditioned video). We describe these two as frozen pretrained representations, and they answer the reviewer question "why not just use a modern pretrained encoder?"

5.3 Finding 1 — every agent breaks, on a change a person would call cosmetic

Repainting walls and changing the lighting (L1) costs every agent between a third and two-thirds of what it could do in the training house. No architecture is immune. This is the paper's central observation.

5.4 Finding 2 — world models lose least, and the advantage is real

Both world models beat both model-free agents at L2, and these survive correction for multiple comparisons: PPO → TD-MPC2 +22.4 points (p = 0.0004), PPO → DreamerV3 +33.5 points (p = 0.0017).

Which kind of world model is better remains unresolved. DreamerV3 (redraws the image) versus TD-MPC2 (no decoder) is 11 points, p = 0.17 — not significant. An earlier single-house result suggested DreamerV3 was clearly better; across five houses that does not hold, and we report it as open.

5.5 Finding 3 — domain randomisation only appears to work at a small budget

comparison at L2150k steps300k steps
PPO vs PPO + augmentation+24.4 points, p = 0.0001+6.7 points, p = 0.11 (not significant)
PPO vs TD-MPC2+26.0 points, p < 0.0001+22.4 points, p = 0.0002

Two mechanisms, both real. Jittered inputs are harder to fit, so at a shared budget the augmented agent had not converged (0.835 in-domain vs PPO's 0.920) — a smaller denominator flatters the ratio. But also its absolute L2 success fell with more training, 0.474 → 0.354. Augmentation delays overfitting to the training house; it does not prevent it. This claim is only available because we kept both budgets instead of overwriting the first.

5.7 Finding 5 — a large pretrained encoder does not fix this

The obvious objection to all of the above is "your agents learned vision from 300k frames of one room; use a modern pretrained encoder and the problem goes away." It does not.

comparison at L1differencepverdict
PPO vs MAEMAE worse by 18.4 points0.017significantly worse
PPO vs JEPAJEPA worse by 4.9 points0.48statistically a tie

Neither 631M-parameter encoder, pretrained on millions of internet images, beats a small CNN trained from scratch inside a single room. The honest claim is "no better", not "worse" — that only holds for MAE.

Suggestive but not established: I-JEPA beats MAE in the same direction at every rung (14.3 points at L2, raw p = 0.022), which would say that pretraining to predict representations transfers better than pretraining to redraw pixels. It does not survive correction across all 15 pairwise comparisons (p = 0.17). Discussed in section 6.

5.8 Finding 6 — what changes matters more than how much changes

Figure 3. (a) Per house: how much the L1 shift alters the camera image, against how much success is lost. Five houses, so a correlation test here can only detect a near-perfect relationship. (b) Within each house: what each rung adds to the image, against what it costs. The target swap adds about 1 unit on a 0–255 scale and costs PPO 0.47 success; added clutter changes the image seven times more and costs nothing.

Panel (b) is the stronger evidence, because it is within-house: the smallest image change in the whole ladder — restyling one object — is among the most damaging, while a much larger change (clutter) is free. Panel (a) is suggestive of a relationship (rank correlation +0.80) but with five houses cannot settle it either way. The defensible claim is "what changes matters, not only how much".

6. Statistics, and an honest problem

All tests are permutation tests that shuffle labels within each house, so between-house differences cannot manufacture a result. The target test is exact — it enumerates all 1,048,576 sign patterns rather than sampling. Every script self-tests on cases with known answers, and each result was recomputed by an independent implementation.

The problem: comparing six agents means 15 pairwise comparisons, and some will look impressive by chance. Correcting for that raised the bar, and two results fell below it:

claimraw pafter correction across all 15
I-JEPA beats MAE0.0220.17 — not significant
PPO + augmentation vs TD-MPC20.00640.058 — not significant

The second is notable: it was significant when we had four agents. Adding two more agents made an existing result harder to defend without a single number changing.

Decision needed. Either correct across all 15 comparisons, or treat the pre-specified comparisons as their own smaller family. The second is defensible here — the matched JEPA/MAE pair and its single question were written into the project log with timestamps before those runs started, so it is not a post-hoc fishing expedition. But it is a judgement call a reviewer may push on, and we should agree a position rather than pick whichever is more flattering per claim.

7. Limitations we will disclose

  • DreamerV3 reliability. 5 of its 25 runs never learned the training house. It needs more samples than the others; at 150k it was worse still. Reported, and excluded only from ratio calculations.
  • Same seed, different agent. Retraining a cell with an identical seed produced very different results (one DreamerV3 cell: 0.24 vs 1.00 in the training house). GPU non-determinism means a seed does not pin a run. Only multi-seed means are meaningful.
  • Trainable capacity is not matched for the frozen-encoder agents — 0.17M parameters against PPO's 4.8M. Inherent to freezing an encoder and standard in that literature, but it is an asymmetry. It does not affect JEPA-vs-MAE, which share an identical head.
  • One task type. Everything is object-goal navigation. A sequential-navigation variant is built but not run.
  • Image change is measured from the starting view only, so a target that is far away or out of frame at the start registers as almost no change.
  • Five houses limits per-house statistics; the target control runs on the four houses whose target could be restyled.
  • Reward is dense-shaped and success auto-terminates, which is easier than the strict Habitat protocol.

8. Status and what we would like to decide

All experiments for the paper are complete: 250 trained agents across two budgets, every figure and table generated from the committed data by script, nothing transcribed by hand. Writing was scheduled to start 27 September against the 7 October deadline.

Questions for you:

  1. The multiple-comparison position (section 6) — pre-specified families, or correct across all 15?
  2. Is it worth 5 more seeds on JEPA and MAE to settle whether representation-pretraining really beats pixel-pretraining? Roughly 30 hours of cluster time. It would have to be pre-registered first, since we have already seen the result.
  3. Workshop paper now, or build toward a conference submission? You raised this. Our view: the benchmark and these six agents are a complete workshop paper today. The natural conference-scale extension is a planning agent built on a video world model — imagine the consequence of an action, score it, act — which is TD-MPC2's structure with a pretrained imagination. That is a new method rather than another column, needs weeks of work, and cannot meet this paper's budget-parity rule, so we would not attempt it before 7 October.
  4. Authorship order — we assume Aarav, Vishwas, Rao unless you would order it differently.

9. Reproducibility

Every number here regenerates from committed files by running a script. The experiment tracker holds 946 rows — one per trained agent per rung — each carrying the git commit and cluster job id that produced it. Raw per-episode CSVs, the tracker, and the paper tables were cross-checked and agree to three decimals on all six agents.
